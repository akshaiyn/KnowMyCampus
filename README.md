# KnowMyCampus

## Interactive Campus Discovery Platform

KnowMyCampus is a web-based campus discovery platform developed as a
Semester 5 mini project. The website provides students, faculty and
visitors with easy access to information about the campus, academic
departments, facilities and important campus locations.

## Features

- 🏫 Academic Departments
- 📚 Campus Facilities
- 🗺️ Interactive Campus Map
- 🤖 AI Assistant
- 🔎 Campus Search
- 📍 Important Campus Locations
- ℹ️ About the Project
